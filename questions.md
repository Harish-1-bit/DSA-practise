q1. Given an integer n, build a right-angled triangle made of stars and return it as an array of strings, where each string is one row of the triangle.

q2. Given an integer n, build a centered pyramid of stars and return it as an array of strings, where each string is one row.

q3. Given an integer n, build an inverted pyramid of stars and return it as an array of strings, where each string is one row.

q4. Given an integer n, build an n × n square where the border is drawn with the * character and the inside is left empty. Return the square as an array of n strings, one per row.
